# Carpeta /music

Coloca aquí tu archivo de música con el nombre:

- `cancion.mp3`

La web nunca reproduce música automáticamente: aparece un botón flotante
(abajo a la derecha) para que Miriam decida cuándo activarla o pausarla.

Si quieres usar otro nombre de archivo, edita la ruta `src="music/cancion.mp3"`
dentro de la etiqueta `<audio>` en `index.html`.
