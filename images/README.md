# Carpeta /images

Coloca aquí las fotografías de la galería de recuerdos (Pantalla 3).

Por defecto, `script.js` busca estos nombres de archivo (puedes cambiarlos
editando el array `CONFIG.memories` al principio de `script.js`):

- `foto-1.jpg`
- `foto-2.jpg`
- `foto-3.jpg`
- `foto-4.jpg`
- `foto-5.jpg`
- `foto-6.jpg`

Recomendaciones:

- Usa fotos en formato `.jpg`, `.png` o `.webp`.
- Preferiblemente en horizontal (relación 4:3) para que se vean perfectas
  en el marco del carrusel.
- Si un archivo no existe todavía, la web mostrará un marcador de posición
  elegante en su lugar, así que puedes ir añadiendo las fotos poco a poco
  sin que nada se rompa.
- Junto a cada foto puedes escribir un pequeño recuerdo editando el campo
  `caption` correspondiente en `CONFIG.memories` dentro de `script.js`.
